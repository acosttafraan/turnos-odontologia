# Traspaso de C-07

## Qué se hizo

Se agregó la API local con salud, disponibilidad por prestación, confirmación de reservas y agenda diaria. La demo carga una franja hábil de 08:00 a 16:00, «Consulta general» de 20 minutos y datos ficticios. El servidor calcula el fin y verifica el solapamiento en el mismo tramo síncrono en que guarda el turno.

## Cómo se verificó

En Windows con Node 24.20.0, `node --test` pasó con 36 pruebas. Se verificaron los ejemplos del [README](../../README.md) en una copia recién clonada con los cambios locales superpuestos. Las pruebas HTTP comprueban el último horario permitido, el rechazo de un turno que termina fuera de la franja y la persistencia de una sola reserva ante dos pedidos simultáneos.
