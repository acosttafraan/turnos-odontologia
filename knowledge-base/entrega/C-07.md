# Traspaso de C-07

## Qué se hizo

Se agregó la API local con salud, disponibilidad por prestación, confirmación de reservas y agenda diaria. La demo carga una franja hábil de 08:00 a 16:00, «Consulta general» de 20 minutos y datos ficticios. El servidor calcula el fin y verifica el solapamiento en el mismo tramo síncrono en que guarda el turno.

## Cómo se verificó

En Windows con Node 24.20.0, `node --test` pasó con 36 pruebas. Se verificaron los ejemplos del README en una copia recién clonada con los cambios locales superpuestos. Las pruebas HTTP comprueban el último horario permitido, el rechazo de un turno que termina fuera de la franja y la persistencia de una sola reserva ante dos pedidos simultáneos. [README](../../README.md)

El equipo confirmó que el commit `f2358c6` pasó `node --test` y la comprobación del README con datos ficticios en Ubuntu 24.04 con Node 22.18.0. [Evidencia de GitHub Actions](https://github.com/acosttafraan/turnos-odontologia/actions/runs/45716508964)
